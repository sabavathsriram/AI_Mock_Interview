# Data Structures in Computer Science

## What are Data Structures?

Data structures are specialized formats for organizing, processing, and storing data. They define the relationship between the data and the operations that can be performed on the data.

## Importance

- Improve program efficiency
- Enable solving complex problems easily
- Help in resource management
- Critical for algorithm design

## Linear Data Structures

### Arrays
- Contiguous memory allocation
- Fixed size
- O(1) access time
- O(n) insertion/deletion

### Linked Lists
- Dynamic memory allocation
- Variable size
- O(n) access time
- O(1) insertion/deletion (if position known)

### Stacks
- Last In First Out (LIFO)
- Operations: push, pop, peek
- Use cases: function calls, expression evaluation, undo/redo

### Queues
- First In First Out (FIFO)
- Operations: enqueue, dequeue, peek
- Use cases: task scheduling, BFS, print queue

## Non-Linear Data Structures

### Trees
- Hierarchical structure
- Root node, internal nodes, leaf nodes
- Binary Tree: Each node has at most 2 children
- Binary Search Tree: Left child < Parent < Right child
- Balanced Trees: AVL, Red-Black Trees

### Graphs
- Collection of nodes and edges
- Directed or undirected
- Weighted or unweighted
- Traversals: BFS, DFS

### Hash Tables
- Key-value pairs
- O(1) average lookup
- Collision handling: chaining, open addressing

## Choosing the Right Data Structure

Consider:
- What operations are most frequent?
- What is the size of data?
- Memory constraints?
- Time complexity requirements?

## Common Algorithms

- Sorting: Bubble, Quick, Merge, Heap Sort
- Searching: Linear, Binary Search
- Graph: DFS, BFS, Dijkstra
- Dynamic Programming
- Greedy Algorithms

## Interview Tips

- Understand trade-offs between data structures
- Know the time and space complexity
- Practice implementing common structures
- Be able to choose appropriate structures for problems
- Understand real-world applications
